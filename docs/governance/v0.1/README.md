## Scope

v0.1 defines governance records and evaluation contracts. It does not
implement an evaluator, Bootstrap, Doctor, executable Audit, CLI, MCP,
background enforcement, automatic remediation, or any project-specific
business authority.

MUST/SHOULD/MAY now describe the accepted v0.1 contract. A project adopts the
standard by recording the exact version in its own profile; that declaration
is not conformance evidence. Executable schemas and tooling require separate
future authorization.
