# Sub Agent execution

Delegation is optional. Use it when a concrete independent question, parallel read-only search or isolated implementation unit improves throughput or context quality.

## Hand a unit enough context

- Task objective and accepted authority reference.
- Repository/ref, required files or owning interfaces, and real dependencies.
- Read-only or bounded write role, expected observable outcome and return evidence.
- Actual execution-tool constraints when relevant.

**Reading units** may run concurrently on shared safe material. **Writing units** need disjoint changed state or an explicit integration order to avoid lost work. The receiving runtime enforces real permissions and selects models/tools.

Review evidence once at integration. Retry or diagnose only the affected failure; cancel obsolete work. Require an additional delegation layer only when a genuine independent task demands it and the environment supports it.

A worker's conclusions are inputs to the owning task, not a second source of task authority. A cross-context handoff uses `agent-handoff` only when responsibility actually moves.
