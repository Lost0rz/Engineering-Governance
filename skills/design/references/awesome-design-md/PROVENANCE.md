## Adaptation status

The upstream repository describes `DESIGN.md` as a plain-text design-system document for AI/design/coding agents and maintains many analyzed public-site examples. Its README documents recurring sections such as visual theme/atmosphere, semantic color roles, typography, component styling, layout principles and extended design guidance.

The local module is a new authority-safe synthesis contract inspired by that concept. It does **not** vendor upstream brand DESIGN.md files, previews, brand assets or extracted tokens. It deliberately changes the usage model from “copy another site's DESIGN.md” to “synthesize a target-project bounded design specification from the project's own authority and the current Design decisions.”

External brands are therefore treated only as optional conceptual references; the target project's existing design system/brand authority always wins.
