# Engineering Governance (optional routing hint)

The installed `project-governance` Skill is the default for engineering work. Choose `design`, `solution-design`, `evidence-audit`, `incident-doctor`, `domain-navigation`, `execution-orchestrator`, `agent-handoff` or `project-profile` by actual outcome. Loading every Skill is unnecessary.

Current authenticated user intent and host/tool permissions authorize writes. An Issue/PR may contain the plan but is not a separate approval, comment, grant or writer lock.

Project `AGENTS.md` provides local product/runtime constraints. Reuse current task/PR, run proportionate checks, and request an external decision only for real scope or consequential risk changes.
