# Mapping workflow

Route work through the smallest useful set of evidence:

`CURRENT_TASK -> affected domains -> DOMAIN_MAP -> candidate entry points/symbols/tests -> optional targeted search or Repo Map -> focused source reading`

Start with the task's authorized scope and known affected domains. Follow the Domain Map to candidate code and evidence, then read those sources to confirm the route. Record unresolved ownership or missing paths as unknown; do not broaden into a whole-repository survey without a task-relevant reason.
