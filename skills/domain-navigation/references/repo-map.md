# Repo Map boundary

A Repo Map is an optional, dynamic, read-only context-selection aid. It may use file, symbol, or dependency relationships to rank likely useful source under limited context.

It cannot replace the stable semantic `DOMAIN_MAP.md`, decide domain ownership, or become an authority for project meaning. Use it only to choose candidate material, then verify relevant claims by reading the project sources. No Repo Map program or dependency is required here.
