# Optional navigation helpers

This Skill requires no executable navigation helper. Task-to-source routing works from accepted semantic authorities, focused direct source reading, and an optional derived navigation projection only when that projection adds durable routing value.

Any future helper needs a measured navigation gap and separate authorization. It must remain optional and read-only, with no daemon, central index, database, vector store, automatic mutation of semantic authorities or navigation projections, MCP/external-service prerequisite, or hidden dependency. It must not decide ownership or authority, authorize work, diagnose incidents, or replace direct source verification.
