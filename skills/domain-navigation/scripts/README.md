# Optional navigation helpers

Version 1, including Phase C, requires no executable navigation helper. This directory contains no script, and task-to-source routing works from the semantic Domain Map plus focused direct source reading.

Any future helper needs a measured navigation gap and separate authorization. It must remain optional and read-only, with no daemon, central index, database, vector store, automatic Domain Map mutation, MCP/external-service prerequisite, or hidden dependency. It must not decide ownership or authority, or replace direct source verification.
